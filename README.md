# Mon Patrimoine

Application web installable (PWA) pour gérer gratuitement un patrimoine immobilier et foncier depuis un téléphone Android.

## Fonctionnalités disponibles

- plusieurs sociétés ou comptes propriétaires ;
- forêts, prés, terrains, habitations et immeubles ;
- références cadastrales et surfaces ;
- plusieurs logements par bien ;
- plusieurs locataires sur un même terrain ou immeuble ;
- loyers mensuels et coordonnées ;
- fonctionnement hors connexion ;
- données conservées localement sur l’appareil.

## Lancer l’application

Ouvrez `index.html` via un serveur web local ou publiez la branche sur GitHub Pages. Sur Android avec Chrome, utilisez ensuite **Ajouter à l’écran d’accueil** ou le bouton **Installer**.

> Cette première version stocke les données dans le navigateur. Une prochaine version ajoutera la synchronisation sécurisée, les documents et la carte cadastrale.
