# Compilation Android

La branche `v5-android` déclenche automatiquement GitHub Actions.

1. Ouvrir l’onglet **Actions** du dépôt.
2. Ouvrir le workflow **Build V5 Android APK**.
3. À la fin du build, télécharger l’artefact **Mes-Proprietes-V5-APK**.
4. Décompresser l’archive et installer `app-debug.apk` sur le téléphone Android.

L'APK debug est installable directement. Android peut demander d'autoriser l'installation d'applications provenant du navigateur ou du gestionnaire de fichiers.
